# Conditional retained-byte registration bridge

`registration_bridge.freeze_registration` consumes:

- Exact immutable handoff geometry JSON bytes, including four real measured packet AX frames and four real measured 2×2-point feature AX frames.
- The full retained BGRA baseline bytes, dimensions/stride, and independently expected retained-frame SHA256.
- Caller-owned `direct_geometry.RasterIdentity`: session, owner PID/window ID, actual raster dimensions, AX viewport and orientation only. Screenshot baseline supplies no SCStream content rectangle or scale metadata, and the adapter never invents those fields.
- An immutable tuple of `(filename, exactBytes)` for the actual contiguous original `event-001.json`… prefix. It checks all eight source-tagged draw=1 receipts, subsequent draw errors/gaps, and the initial inventory. Each original leaf hash and the ordered inventory hash are bound into the proof. Caller must establish owned collection, prefix completeness, all journal error files, and write-cost validity. This adapter cannot prove completeness by parsing filenames.
- The exact source-hash map bound by the caller's owned source launch. `source_hashes()` provides a local measurement, not authorization; taking a fresh map from arbitrary code is not producer/source ownership proof. Dependency bytes are checked before and after registration, and the reviewed packet and BGRA decoder constants are separately checked.

It returns a frozen `RegistrationResult` containing provisional `FrozenRasterGeometry`, six actual same-sample packed `Crop` objects, canonical `plan_bytes`, and canonical `proof_bytes`. The plan uses exact native schema `p1-direct-roi-plan-v1`, fixed role order control, marker, anchor-1 through anchor-4, and `geometrySHA256 = SHA256(exact request bytes)`. Proof hashes bind both the full strided frame and its packed baseline counterpart, source map, request, event bytes, decoded packets/components, fit polygon, holdout, six crops, live marker and plan.

No supplied point estimate, selected transform, nominal fixture position, or decoder float board center is promoted to exact geometry. Runtime AX Doubles are preserved as their exact round-tripped binary rational values. Feature correspondences use the whole measured AX rectangle × whole actual qualifying pixel-support interval. Three features fit; the fourth only rejects incompatible fits. Crops come from the unchanged fit region, and no failure triggers a fit retry, clamping, or alternate assignment.

Every anchor ROI contains the entire measured packet-plus-feature source envelope. The actual retained ROI bytes are decoded again to the exact full nonce/ordinal and integer ring support seen in the full baseline. The full Copy Details control and live marker are retained, every retained ROI must be distinct and in bounds, and the complete baseline-ready control's feasible pixel envelope must not overlap any anchor ROI. The current local 1MiB combined frame ceiling is enforced. The extraction helper's `record=1` is a local copy ordinal, not a native stream frame index; native indices remain zero-based.

The live strip uses the independently reviewed whole-source-cell intersection. Every retained unit pixel must fit inside the corresponding source cell for every feasible transform; the unchanged decoder requires opaque uniform values and all 24 registration/data cells. No ideal-center or guessed rendering-error constant is introduced. Native filtering still needs independent validation.

## Remaining prerequisites

Source locality/exclusivity is conditional: a qualifying component must come exclusively from its corresponding source-owned clipped UIView. A nonce board plus adjacency does not authenticate a same-colored replacement. One upright positive axis-aligned affine transform, native rendering/filtering behavior, owned simulator/GUI/window/helper lifetime, source-bound AX geometry, complete retained byte collection, live first complete stream frame and display timestamp are separate mandatory checks. The baseline here is geometry-only, never timing evidence. Every native, presentation, locality-established and admission flag remains false.

The bridge does not implement host ownership, complete frame scheduling/coverage, OCR, clock mapping, observer-cost acceptance, cleanup, or final admission. These outputs are an integration primitive, not an autonomous acceptance gate.

## One-shot actual stream join and replay

`GeometryValidator` rejects `FrozenRasterGeometry`. `RegistrationJoin` requires the exact provisional proof hash and accepts exactly one actual first-complete manifest plus packed pixels, manifest hash, and source-bound native timebase. It uses `packed_frames.inspect_first` unchanged. Actual `contentRect`, `contentScale`, and `scaleFactor` are taken solely from the source-bound complete stream row and produce the final immutable `Identity`. The baseline screenshot and content filter never supply substitutes. All four actual ROI packet supports, opaque feature supports, crop bounds/hashes and marker cells are checked again. The original fit, viewport and six ROI bounds are copied unchanged: no refit, holdout narrowing or crop adjustment.

The resulting `StreamBindingResult` retains final frozen geometry, exact final proof bytes, actual crops/anchors, and the already-validated `GeometryValidator` accumulator. The proof binds provisional baseline proof hash, plan hash, first complete manifest hash and packed hash, native index/display ticks/timebase, actual native geometry, exact retained packet/feature observations and unchanged-fit assertion. It explicitly states that `geometrySHA256` means AX-request bytes only; the separate pixel baseline/final proof hashes establish their respective bindings. It never calls the request hash a pixel geometry proof.

Promotion is consumed on success or failure; retries and duplicate promotion reject. Frozen identity/geometry/results and proof bytes cannot be mutated through normal assignments. Source drift, metadata mismatch/missing fields, changed actual packet or feature support, changed crop bytes, clipping/unknown pixels, or failed replay latches failure. Source locality, native ownership, actual-first-frame provenance and full delivered-record inventory remain externally required.

`validate_complete_frame(binding, verified_row, validator=...)` consumes the parent's strict `packed_frames` output for each complete retained row. It re-decodes four nonce boards/features and the live strip directly from the six actual crops, verifies packed bytes and crop geometry, and returns the actual marker plus geometry proof and native index. It never fills omitted pixels to invent a full frame. Use `binding.validator` for continuation after the first frame. For final replay, create a fresh `GeometryValidator(binding.frozen)` and feed the bound first complete frame again, followed by every later complete frame. Starting later is rejected. All leading started/idle and later noncomplete records remain required by the separate complete-census/clock coverage validator.
